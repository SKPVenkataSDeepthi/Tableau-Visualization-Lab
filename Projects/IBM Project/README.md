## 📌 Overview

This project was completed as part of the **IBM Skills Network Guided Project – Creating Charts and Dashboards using Tableau**.

The dashboard analyzes customer purchasing behavior, revenue generation, marketing effectiveness, and customer loyalty using interactive Tableau visualizations.

## 🎯 Project Objectives

- Visualize revenue by geographic location
- Analyze quantity sold across product categories
- Evaluate coupon campaign performance
- Compare customer lifetime value with product sales
- Understand customer loyalty behavior
- Build an interactive executive dashboard
